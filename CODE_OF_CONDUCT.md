# Community code of conduct

We want OpenBot to be a focused, respectful and safe open-source project.

- Be constructive and specific when reviewing ideas or code.
- Respect privacy. Never post credentials, personal data or captured computer content.
- Do not use project channels for harassment, threats or discriminatory behavior.
- Disclose conflicts of interest when recommending vendors, models or integrations.

Maintainers may remove content or participation that violates these expectations. Security reports
must follow [`SECURITY.md`](SECURITY.md).
