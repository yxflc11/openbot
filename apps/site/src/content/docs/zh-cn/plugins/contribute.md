任何人都可以开发兼容 MCP 的服务。希望加入 OpenBot 经审核目录时，请使用 [插件提交表单](https://github.com/yxflc11/openbot/issues/new?template=plugin-submission.yml)。

提供公开源码仓库、精确发布或 commit、开源许可证、安装步骤、认证方式，以及工具/资源/提示词/视图声明和全部外部影响。说明支持的平台，提供可复现的成功与失败测试。不要提交真实令牌、账户凭据或私人对话。

维护者会审核协议兼容、权限、依赖来源、维护情况、使用流程与测试证据。目录必须指向审查过的版本，明确运行要求。上架不会替已有用户自动安装，每位用户仍需自行预览和授权。

如果某项能力适合加入核心产品，先讨论范围，再扩展 Server 或依赖。优先复用开放标准与维护中的项目，记录研究和许可证决定，权限留在 Server，并提供英文主文档和中文翻译。贡献流程见 [CONTRIBUTING](https://github.com/yxflc11/openbot/blob/main/CONTRIBUTING.zh-CN.md) 与 [仓库地图](https://github.com/yxflc11/openbot/blob/main/docs/REPOSITORY_MAP.zh-CN.md)。
