设置决定 Server 使用的模型提供方和连接。API 密钥保存一次即可，后续修改配置可保留已保存密钥，界面不会重新显示原始密钥。明确启用 Agent 后才会开始推理，仅保存密钥不代表允许自动消耗额度。

选择支持工具调用和所需文件类型的模型。各提供方兼容程度不同：能回复文字不代表一定支持工具、图片或 PDF。连接错误区分密钥被拒绝、限流和模型不可用，不要把账户密码发给 Bot 来修复配置。

## 凭据持久保存

本地桌面的启动身份由操作系统加密保存：Windows 使用 DPAPI，macOS 使用钥匙串。模型设置和插件令牌保存在 Server。重新打开应用复用这些文件，不需要重新配置模型。

macOS 的“Safe Storage”弹窗要求的是系统登录钥匙串密码，不是模型密钥。未签名预览包更新后，系统可能再次要求授权；缺少稳定签名身份时，应用不能保证消除系统提示。升级时保留现有数据目录，不要通过删除凭据文件来消除弹窗。

## 工作区偏好

外观、侧栏、详情面板、文字大小、时间格式、减少动效和发送快捷键属于界面偏好，不改变 Bot 权限。远程连接保存前核对 Server 地址；更换连接不等于迁移本地工作区。
