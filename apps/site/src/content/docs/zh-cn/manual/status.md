description: "功能全貌与实现边界 — OpenBot"
---

本页把你的工作设想与当前实现逐项对应。安装包和特定操作系统的支持结论，需要核对对应发布 commit 的验证记录。

| 部件 | 实际功能 | 使用边界 |
| --- | --- | --- |
| 侧栏与导航 | 切换频道、Bot、插件、自动化和设置 | 当前客户端会话保留草稿 |
| Bot 档案 | 身份、审核记忆、技能和演化证据 | 模型文字不能分配权限 |
| 私聊 | 与一位 Bot 持续对话 | 成员固定 |
| 群组频道 | 明确接收者、引用回复、共享任务上下文 | 单次最多六位接收者 |
| 协作分工 | 并行同事、异步委派、汇总子任务结果 | 六个根任务，两层委派，四个后代 |
| 任务动态 | 状态、停止、重试、执行中补充指令 | 追加指令不能撤回已完成操作 |
| 增量回复 | 提供方文字草稿与重连快照 | 正式消息持久保存，中断草稿不跨崩溃恢复 |
| 消息操作 | 气泡侧边表情、回复、复制和详情 | 表情目前表示单一 Owner 自己 |
| 附件 | 原件下载、本地 Office/PDF/OCR、明确转写 | 八个文件、合计 20 MiB，并受模型和解析边界限制 |
| 语音 | 麦克风录制、试听、添加附件 | 转写单独选择，不自动外发 |
| 分享 | 下载产出，或直接导出 Bot 自己 | 先预览内容，排除密钥和实时授权 |
| 插件 | 工具、资源、提示词、隔离 Apps、审核后更新声明 | MCP 子集，不自动安装、不含 OAuth 或 Apps 工具调用 |
| 插件目录 | 经审核元数据与社区贡献流程 | 上架不等于自动授权 |
| 自动化 | 通过相同 Server 权限边界创建定时任务 | Server 需要持续运行 |
| 设置 | 保存模型凭据与工作区偏好 | 仍遵循操作系统凭据与签名规则 |
| Windows 桌面 | 本地服务或远程客户端，按用户安装 | x64，原生证据以 CI 运行记录为准 |
| 官网 | 中英文手册、搜索、协议与贡献入口 | 静态站点，不持有工作区秘密或托管模型账户 |

目前不宣称无限 Agent、崩溃后自动重放、多真人协作、完整通用 MCP 宿主或所有平台的电脑控制一致性。电脑执行由独立 Worker/Provider 部署和审批流程提供，办公室可视化仍为延期的可选插件。
