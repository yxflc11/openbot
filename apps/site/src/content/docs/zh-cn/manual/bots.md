Bot 是有持续身份、档案和经过审核的能力的协作成员，身份由 Server 管理。模型在文字里说“换成另一个 Bot”不会获得对方权限。

## 创建同事

从工作区创建入口新建 Bot，填写名称、角色和明确职责。仅用模型工作的 Bot 选择不需要工作电脑的配置。进入档案可以查看身份、记忆、技能和演化记录。私聊固定发给这位 Bot；群组频道可以加入多位成员。

## 记忆、技能与演化

记忆是明确保存的信息，并不代表可以任意读取所有对话。技能可通过 `SKILL.md` 导入，并有待审核、已验证、暂停、撤销等状态。任务只获得该 Bot 已分配且已验证的技能。学习得到的提案经过审核后才能进入长期能力。

演化页面记录变更及证据。员工学习方向受到 [Hermes Agent](https://github.com/NousResearch/hermes-agent) 启发，OpenBot 保留这项来源说明。

## 分配与分享

通过频道成员菜单加入 Bot。Bot 可以把有边界的子任务交给另一位频道成员，对方使用自己的权限执行。移除成员会停止相关活动任务树，但保留历史和档案。分享 Bot 导出经过预览的可移植包，不会把你的 API 密钥或现有工具授权交给接收者。
