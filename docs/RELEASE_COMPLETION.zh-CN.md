## 工作区与频道

| 部件 | 当前功能 | 与产品设想的对应和边界 |
| --- | --- | --- |
| 侧栏 | 搜索频道/Bot，进入私聊或群频道，保留本地草稿和阅读位置 | 已有单一 Owner 工作区；尚非多人聊天系统 |
| Bot 资料 | 职责、简介、外观、执行偏好、经审核的记忆和技能 | 每位 Bot 有自己的身份，身份和权限由 Server 管理 |
| 消息气泡 | 引用回复、富文本、来源链接、文件、时间分组、任务详情 | 操作栏位于气泡外侧中部，悬停或键盘聚焦显示；复制和详情收入省略号菜单，符合此次位置要求 |
| 表情和成员 | Owner 表情回应、群频道加入/移除 Bot | 移除时取消该 Bot 的活动任务与后代，保留历史；私聊成员固定 |
| 原生任务 | 调用配置好的模型、受限联网与来源读取、产出报告、显示进度和取消 | 需配置提供方；电脑控制由独立 Worker/Provider 执行 |
| Bot 分工 | Bot 按频道身份调用另一位 Bot；可继续独立工作，汇合下级结果后交付 | 已实现分工聊天；最多同时六个根任务、两层委派、四个后代，共享五分钟预算；不承诺崩溃后自动重放 |
| 逐段回复 | 模型回复过程中显示文本，正式消息到达立即替换草稿 | 原生适配器按能力支持；MiniMax 保留非流式路径 |
| 追加指令 | 给选定的排队/运行中原生任务补充文本，下个安全步骤消费 | 每个任务累计八条，每条 4,000 字符；不撤回已完成操作，不自动影响兄弟任务 |
| 定时任务 | 创建固定间隔任务、暂停/恢复、删除、查看上次结果，避免重叠执行 | 服务必须运行；更改提示或时间需创建新任务 |

## 附件、分享、设置与插件

| 部件 | 当前功能 | 与产品设想的对应和边界 |
| --- | --- | --- |
| 附件入口 | 上传、粘贴、拖放支持的文件，查看元数据并下载原件 | 扩展到 Office/ODF/PDF 文本提取、图片 OCR、带密码 PDF；操作有文件、输出、时间及解压限制，不执行宏 |
| 语音与媒体 | 点击录音、结束、试听、丢弃或加入草稿；显式转写支持的音视频 | 不自动上传录音；转写需受支持且已配置的提供方，可能将选中文件传出本机 |
| 频道文件 | 查看可用文件与回收站、软删除、恢复、清理超过七天且不被引用的文件 | 已有任务仍保留不可变原件；不能任意读取电脑文件 |
| 成果下载 | 保存产出报告和原始附件 | 成果仅在对应 Bot 最后的正式消息展示一次 |
| 分享 Bot | 图标入口，预览、导出和导入职责、简介、外观、执行偏好与已审核技能 | 分享的是可复用 Bot，导入后使用新身份；不包含私人记忆、聊天、密钥、插件授权或原有权限 |
| 模型与偏好 | 提供方预设、模型选择、加密保存密钥、明确启用 Agent、外观与发送偏好 | 保存的密钥重复使用；系统钥匙串密码不是 API 密钥 |
| 再次启动 | 首次准备和日常打开分开；复用原有数据、配置和身份，日常只显示简短连接状态 | 不因解密失败重建身份或改用明文；未签名应用变更仍可能触发系统信任提示 |
| MCP 工具 | 审核声明、按 Bot 授权、按配置审批写操作、撤销授权、预览更新 | 插件不止技能；更新清空旧授权，模型不能自行扩大权限 |
| MCP 资源和提示词 | 按 Bot/频道读取、预览并加入草稿；原生任务可读取获授权资源 | 外部资料不成为指令权限，也不能伪造附件引用 |
| MCP Apps | 官方 SDK 桥接，隔离的交互界面，限定的资源访问 | 不承诺完整支持任意应用调用、宿主跳转、存储、网络和设备权限 |
| 社区扩展 | 公开协议、固定版本目录、示例和贡献入口，维护者审核纳入 | 目录不是自动安装或默认信任；无需把每种新功能写进核心 |

## 官网与工程整理

官网包含中英文产品介绍、14 组双语手册、搜索、安装与插件开发指南。交互演示直接使用实际侧栏和频道组件，明确标注示例数据、不连接模型。支持播放、暂停、重播和逐段回复，尊重减少动效设置。它使用实际界面，不把生成的示意聊天图冒充产品截图；未声称所有 Grok 状态都已逐像素一致。

仓库审查覆盖 OpenBot 全部应用、共享包、Provider、文档、数据库迁移、打包和 CI。补齐模块入口、当前架构、功能归属图和真实数据库测试，移除旧消息操作栏样式。保留已有其他平台代码和用户数据。历史大文件仍是后续按功能拆分的候选，不能声称已经全面重构。详见[工程审查](REPOSITORY_AUDIT.zh-CN.md)。

本地定向测试覆盖身份权限、逐段输出与追加指令、实际解析/OCR Worker、真实 MCP SDK 连接、更新撤权、录音生命周期、恢复启动、弹窗和侧边消息操作。四组隔离 PostgreSQL 测试覆盖 49 个案例；浏览器检查覆盖实际演示、桌面和窄屏、插件隔离、手册搜索。示例数据和模拟媒体测试不等于真实麦克风硬件或付费模型验收。
