- 状态：接受实施
- 日期：2026-09-10
- 维护者：OpenBot contributors
- 验收路径：Owner 看见哪个 Bot 向谁委派，打开子任务，并在接收方独立身份下阅读回复。

## 实现决定

复用标准按钮、列表、现有 Bot 头像和状态标签。按 Server 的 `parentRunId`、`rootRunId`、`delegatedByBotId`、`sourceMessageId` 构建同频道关联，不解析 @ 文本。委派消息归发起 Bot；完成消息归接收 Bot。父任务未加载时明确提示，不编造链接；不呈现跨频道、自引用、循环或发起者不匹配关系。此组件以后可替换，Server 持久关系独立于显示层。

## 调整前实际查看的 Grok Bot 公开参考

2026-09-10 在 Chrome 1470 × 835 查看 [xAI 官方产品页](https://x.ai/bot)。这是当日公开演示，没有可核验的应用版本或提交号。演示显示白色对话面、浅灰圆角 Bot 正文、右侧黑色用户正文、紧凑输入框及小型 Bot 身份。对话中的归属行指出其他 Bot 提供了消息；协作示例使用彩色身份和短交接状态，没有父任务折叠面板。

据此采用浅灰 Bot 正文、黑色用户正文、内联接收方/状态、独立回答身份和紧凑参与者链接。保留真实任务状态、回复动作和 OpenBot 自有头像，不复制 xAI 美术或品牌。公开样张不足以确定所有状态的精确尺寸，因此这是有来源的局部对齐，不是已验证的像素级完整复刻。

[官方频道协作文档](https://docs.x.ai/grok-bot/chat-and-collaboration)描述异步文字交接。OpenBot 本次实际为有界串行同步委派，最多两层、全树四个子任务，不能宣称异步行为一致。[官方 Bot 文档](https://docs.x.ai/grok-bot/bots)区分持续身份与对话历史；共享电脑和公开托管分享不在本次界面范围。

学习演进方向仍归因于 Hermes Agent。本次呈现不增加未经审核的自动记忆更新。

## 代码与素材归属

没有复制或实质改写上游源码；只复用现有 React、原生控件、OpenBot 头像和状态函数。没有引入外部美术素材或新增前端依赖，保留现有许可证。

## 验证与限制

自动验证发起者/接收者、精确委派消息关联、参与者状态、频道过滤、无效循环、缺失父任务和详情回调。真实浏览器使用合成数据检查桌面与窄屏、键盘焦点、溢出和状态变化；没有新增动画。

没有验收已登录 Grok 应用、所有尺寸、真实模型结果或异步能力对等。后端执行由独立集成测试证明，界面截图只证明本次渲染与受测交互。

## 2026-09-10 真实渲染结果

受测路径为合成频道的父任务、Bot 委派、接收方回答，再打开子任务。仓库外临时 Vite 预览 `http://127.0.0.1:5198/` 加载真实组件和生产样式，用合成 API 返回值避免连接真实模型或插件。当前没有 Browser 插件/技能，按测试技能使用已提供的 Playwright 与无头 Chrome；官方参考另用 CUA Chrome 实际查看。没有安装依赖。
