# 调研：跨模型共享联网工具

- 状态：接受
- 日期：2026-09-08
- 负责人：@yxflc11
- 验收：已配置且支持工具调用的模型都能检索、读取公开来源，继续由原模型回答。

复用 OpenAI SDK `7.10.0` 与 Anthropic SDK `0.124.0`，分别完成兼容协议和原生 `tool_use` /
`tool_result` 续轮；保留当前任务所需的不透明推理/签名，不落入历史记录。完整固定版本、官方
契约、候选比较与验证计划见[英文记录](shared-model-web-tools.md)。

Server 把回答模型和检索服务分开。优先使用 `TAVILY_API_KEY`，其次是明确配置的
`OPENBOT_WEB_SEARCH_CONNECTION_ID`，最后复用已有 `MOONSHOT_API_KEY`；不会随意选择已保存账户。
Kimi Formula 的搜索结果可能为密文，需经最多一次工具执行、两次 Kimi 推理转成可读来源摘要，
再交给其他回答模型。转接只接收检索参数，不接收员工聊天历史。检索凭据不发送给回答服务。

所有协议共享四次工具上限、总截止时间、完整批次参数校验和不含正文的审计。失败不自动重试，
不以旧知识冒充实时证据。网页不授予登录、购买、电脑输入或本地访问权限。未复制上游源码，
未新增依赖；托管 API 不宣称是可复现的固定远端实现。

具体模型 ID 仍须支持工具调用。协议契约测试与真实服务调用分开记录；没有相应授权 Key 的
模型不能宣称已经过真实调用验证。

## 验证结果

最终 `npm run check` 已通过。11 个 OpenAI 兼容预设与 Claude 原生协议均覆盖完整工具续轮，
另有凭据路由、历史隔离、参数和输出上限、失败处理测试。

真实 Kimi 转接完成一次 Formula 搜索和两次推理，返回带来源链接的可读证据，没有密文。
实测发现 Kimi 思考模式拒绝强制指定工具的 `tool_choice` 参数，现改为只暴露目标工具，并校验
确实执行完成。Tavily 与其他聊天服务均有契约测试；未持有授权 Key 的服务不宣称真实调用通过。
