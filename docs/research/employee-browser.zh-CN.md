- 日期：2026-09-08
- 负责人：@yxflc11

## 决定与边界

浏览器继续运行在工作主机。Server 新增查看会话、每个查看端独立的接管归属、过期控制、命令关联
和无正文审计；Node 将操作与现有任务按员工串行化。上游单一 `human` 标记不足以区分两个客户端。

复用 PNG 按需刷新提供连续观察，不宣称视频帧率。不向 Client 暴露 CDP、后台令牌、任意端点、
JavaScript、Shell 或文件访问。输入通过 Owner 当前接管会话授权，不会把现有审批扩张为通用租约。
超时或断线后禁止自动重放输入；未明确交还时不能让 Agent 在用户填到一半的页面上恢复操作。

运行时源码原样下载；构建配方改编自上游 MIT Dockerfile，固定 Bun 1.4.2 与归档/镜像摘要，
镜像保留 `/app/licenses/CopilotKit-OpenBot.LICENSE`，分发还须保留 Playwright/Chromium
声明。升级必须保持浏览器和依赖版本一致，并重新执行验收。

## 验证计划

- 协议：无效和超限输入、过期、重复请求。
- Server：会话归属、离线和能力不匹配、独占接管、审计先于副作用、断线和超时清理。
- Provider/Node：端点白名单、私网 URL 拒绝、员工间隔离、人机互斥、响应校验。
- 真实浏览器：合成表单的导航、点击、中文/粘贴、滚动、交还和持久会话。
- 桌面/手机界面：加载、错误、关闭清理和操作反馈；运行 `npm run check`。

视频传输、下载、任意标签页管理和模型自主多步操作是独立验收项。本次不宣称完整 M2、原生桌面
控制或任意网站登录兼容性。
