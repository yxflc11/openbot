# 调研：模型联网搜索与网页读取

- 状态：接受
- 日期：2026-09-08
- 负责人：@yxflc11
- 验收：Kimi 员工对当前信息实际搜索、读取来源并回答，继续旧任务时不再沿用“没有联网工具”的说法。

复用已固定的 OpenAI SDK `7.10.0`（`c22b09bc8bd5feed4ebd02b9f363a1a8b479b5ab`，Apache-2.0），
接入 Kimi 官方推荐的 Formula v1 `moonshot/web-search:latest` 和 `moonshot/fetch:latest`。
完整检索、候选比较、官方文档、声明摘要和验证证据见[英文记录](model-web-search.md)。

运行时不采用远端任意工具声明。Server 只允许已审查的搜索和读取名称、参数和官方地区地址；
每项任务最多四次调用，共享原有总超时，输入、回复和累计上下文均有界。失败时不自动重试付费
请求，也不以旧知识冒充实时结果。网页内容仅作不可信证据，不授予操作权限。

K3 工具续轮所需的完整 assistant 状态只保存在当前任务内存，不展示、持久化或导出私有推理。
审计只保存工具名和阶段。其他模型服务暂不宣称联网支持；不增加购买、登录或电脑输入权限。
未复制上游源码。Formula 的 `latest` 是可变托管服务，不能宣称远端实现可复现。

真实 K3 测试已在含“没有联网工具”旧回复的续聊中完成三次搜索并返回来源链接。此证据验证
工具可用，不代表模型列出的所有价格都经过独立核验。当前报价必须与历史新闻、预测和建议价区分。

`npm run check` 与 77 项模型/客户端/调度器测试已通过。临时 PostgreSQL 集成验证了仅运行中任务
可记录工具审计，完成后拒绝继续写入。真实 K3 网页读取任务完成了读取、Bot 回复持久化和消息
事件发布，审计仅有 `fetch:started` 与 `fetch:completed`，没有参数或结果正文。测试环境已清理。
