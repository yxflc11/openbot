# ADR-0013：当前版本频道优先，办公室插件化

## 状态

Accepted — 2026-09-03

## 背景

办公室视图有助于理解多 Bot 状态，但它会把当前版本的注意力从真实工作闭环移向空间装饰。当前最重要的是让用户在一个长期频道中指定 Bot、观察执行、处理审批并接收结果。

## 决策

1. 核心 Web 默认选择第一个频道；没有频道时只显示创建频道引导。
2. 桌面侧栏和手机底栏不展示办公室入口。
3. `apps/web` 不导入、不依赖办公室代码。
4. 办公室保存在独立的 `@openbot/office-plugin` workspace 包，由宿主未来显式注册。
5. 插件只消费公开的 Bot、Channel、Run、Node 数据和头像渲染器，不建立第二套运行状态。
6. Bot 组合身份属于 Domain，而不属于办公室插件，因此频道和未来插件显示同一个 Bot。

## 结果

当前构建更聚焦于频道中的多 Bot 对话；办公室仍可独立优化和发布，不会拖慢控制面、频道和执行能力开发。
